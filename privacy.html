Privacy Policy

Fitbit to Garmin Sync is a personal, single-user script operated by Stephen Webb for his own account only.

What data it accesses

With the owner's consent, it reads weight and body fat measurements from the owner's Google Health (Fitbit) account using the read-only scope googlehealth.health_metrics_and_measurements.readonly. It does not request or read any other data.

How the data is used

Each measurement is copied to the owner's own Garmin Connect account. Nothing else is done with it.

Sharing and storage

Data is never sold, shared with third parties, used for advertising, or used to train AI models. The script keeps no copy of the measurements. Its only stored items are the login tokens it needs, kept in a private GitHub repository.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions.
